# Canvas 游戏源码

导出已有 dist 时，只需在解压目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 http://127.0.0.1:8000/；不需要工作台或模型密钥。不要直接双击 HTML。

若修改 TypeScript 源码，再安装 Node.js 并执行 `npm install`、`npm run build`，重新运行静态服务器。

玩法参数位于 src/config.ts，逻辑位于 src/game.ts。模板包含接物、躲避、点击目标三种模式。
接物和躲避支持按住画布左右拖动，或使用方向键/A/D；点击模式点按目标。松手、取消触摸或失去焦点时停止拖动。界面显示剩余秒数，重开重置计时。
导出包含验证过的 dist，可直接用静态 HTTP 服务器预览。浏览器测试的 ?test 模式禁用随机生成并暴露确定性状态，仅用于测试。
