# 网页游戏玩法与交互设计

- 按用户需求选择模式，四种模式均可新建或迭代，不默认三消。需求超出固定模板能力时说明差距并请求澄清，不擅自替换玩法。
- collector 接物：左右移动接金币、躲炸弹；新模板支持键盘与按住画布拖动，显示剩余时间。明确速度、生命、时长及计分。
- dodger 躲避：左右移动避开落下的危险物，生存计分；新模板支持键盘与触屏拖动，显示剩余时间。明确速度、生命和时长。
- clicker 点击：点击目标得分、误点危险物扣命；明确目标刷新、生命和时长。
- match3 三消：8×8 棋盘，相邻交换形成横纵三个及以上同色消除；无效交换回退且不扣步，有效交换扣一步，连锁不重复扣步。明确宝石种类、步数和目标分数；无解重排，达标优先判胜。
- 每种玩法都明确开始、操作反馈、得分、失败或结束、重新开始。颜色之外提供形状或文字线索。
- 验收使用可观察行为，区分固定工具覆盖范围与人工评价的难度、反馈、趣味性。不能用编译成功代替需求满足。
- 当前能力是固定 TypeScript Canvas 模板；不宣称已支持平台跳跃、射击、Unity、多人在线或付费系统。
