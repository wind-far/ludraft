# 三消玩法与交互设计

适用于当前 8×8 Canvas 模板，不代表已完成测试。

- 明确宝石种类、目标分数、可用步数、配色与目标用户。默认交换相邻宝石，横纵三个及以上同色消除。
- 无效交换回退且不扣步；有效交换只扣一步，连锁不再扣步。胜负优先级：达到目标优先判胜，否则步数耗尽判负。
- 开局无已有匹配且至少有合法交换。死局重排不加分、不扣步；重开重置分数、步数、选中状态与动画。
- 操作应支持点击/滑动与键盘，动画结算期间不接受重复交换；颜色之外使用形状辅助识别。
- 验收条件使用可观察行为，区分固定工具可测项与人工判断的难度、反馈、趣味性。
- 不擅自增加模板接口之外的道具、地图或付费功能；若用户提出，明确所需接口变化并请求确认。
