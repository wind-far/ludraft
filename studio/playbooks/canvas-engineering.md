# TypeScript Canvas 实现与审查

- 遵守固定模板导出和入口约束，读取当前代码及三方设计再修改；文件归属由主程编码任务确定。
- 根据已确认模式选择固定模板，不能给接物、躲避或点击作品套用三消接口。
- 接物与躲避检查移动边界、帧时间、碰撞和生命；点击检查坐标换算与命中判定。重开清空上一局状态。
- 三消的棋盘逻辑与绘制状态分离，索引和相邻关系显式检查，连锁和补位有终止边界；无效交换恢复棋盘，输入锁覆盖结算动画。
- 独立文件可并行实现，同文件通过依赖排序；不要覆写另一任务未涉及的改动。
- 不新增外部依赖、动态执行、网络请求，也不改动固定构建、测试或入口文件。
- 审查必须指出对应代码和设计依据，模型审查不能代替实际编译或浏览器运行。
