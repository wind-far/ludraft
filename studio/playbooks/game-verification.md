# 网页游戏验证证据

- 实际测试由固定隔离工具执行，模型负责整理策略和分析证据，不虚构工具调用。
- 按已确认模式选择检查；所有模式验证构建、开始、重开与浏览器异常。
- 三消检查相邻交换、无效回退、单步扣减、消除计分、下落补位、连锁、死局重排、胜负。
- 接物、躲避、点击检查对应输入、真实计分、扣命和结束，不能用三消规则代替。新版入口额外验证 390px 手机布局、触屏拖动/点击及倒计时重开；三消验证触屏交换。旧入口的手机能力未验证时如实说明。
- 编译通过与核心交互通过分开记录。工具未测的新增需求不能标记通过；补充人工验收项。
- 发现问题应写责任角色、阻断级别、可复现操作和代码/日志依据。工具失败不能被主观评价解除。
- 记录随机种子与失败棋盘（工具提供时），区分游戏缺陷、测试夹具问题与环境失败。
- 难度、反馈、趣味性由人工独立评价，不把固定模板或协议模拟结果计入真实模型生成成功率。
