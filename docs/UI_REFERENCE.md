# 画布工作台 UI 规格

参考：用户于本轮提供的三状态 UI 设计图。执行范围为现有项目的界面调整，直接接入真实数据与操作。

- 首页：左侧 196px 导航；中间最大 900px；内容区内的单层标题（让游戏想法，在画布上展开。），首页不渲染全局顶栏或重复的模型配置按钮、花园插画横幅、新建画布与四种创作入口、真实最近项目、需求输入与四类玩法快捷入口。
- 空白画布：浅蓝白点阵背景，顶部项目栏，中央四个添加入口，底部缩放与工具条。填写需求后仍须确认玩法再执行。
- 项目画布：可拖动的参考卡片与真实游戏卡片，底部修改输入；浮动功能栏打开参数、材料、源码、版本、验证、八角色团队、日志与消息面板。
- 色板（依据截图估计）：背景 #f7fbff，点阵 #dce9f5，正文 #172139，次文 #8592a8，主蓝 #0087ff，边框 #e4edf6；白色浮层，12–18px 圆角，轻阴影。
- 字体：沿用系统 PingFang SC / -apple-system；截图无法确认具体字款，不额外依赖在线字体。
- 图标：统一 24px 网格圆角线性 SVG；蓝色游戏手柄品牌标记。
- 花园插画：按用户参考图生成配套环境插画，作为首页装饰；不是模型生成作品的证据。已有游戏保持原有实际渲染。
- 参考图片：本机浏览器保存的画布参考，明确不自动提交模型；文档材料仍经现有上传、核对与引用链路。
- 交互：工具条和卡片悬停 160ms；拖动画布/节点、缩放和视图复位；Escape 关闭面板。尊重 reduced-motion。
- 身份区：导航底部展示默认人物图标、“本地创作者 / 本地工作空间”；当前为本地身份说明，无虚构账户菜单，画布不再显示写死的 W 头像。
- 响应式：小屏收起侧栏，画布节点改为纵向可读布局，工具条可横向滚动，弹层不超出视口。
- 能力边界：图片中的 AI 素材生成不在现有实现范围。使用“视觉方案”与“上传参考”入口；不渲染虚假的生成按钮、任务状态、缩略图或测试分数。

验收：桌面首页、空白画布、真实项目、侧面板操作、缩放/拖动、390px 布局、TypeScript 与构建检查。截图为静态设计稿，未假定其存在额外动画。

- 角色规则弹窗：标题、关闭按钮和一级切换固定在头部；正文独立滚动并隐藏滚动条，正文可通过键盘聚焦，Escape 可关闭弹窗。
